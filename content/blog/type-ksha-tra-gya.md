The forms क्ष, त्र and ज्ञ are common Devanagari conjuncts. They are rendered as connected visual shapes, but a Unicode text sequence often contains more than one underlying character. A virama suppresses the inherent vowel of the first consonant so that it can join the next consonant. The exact sequence you type depends on the input method and layout.

For Unicode typing, क्ष is commonly represented as क followed by virama and ष; त्र as त plus virama plus र; and ज्ञ as ज plus virama plus ञ. A shaping engine combines these sequences into familiar glyphs. Do not confuse the number of visible clusters with the number of code points or key actions. A practice tool should compare the sequence expected by its selected layout.

Start by typing each conjunct slowly and noticing the order of its component keys. Then place the form in short words and sentences. If the output looks separated or incorrect, check whether your selected input method supports conjunct composition and whether the virama is being entered. Fonts and rendering systems can affect appearance, even when the underlying Unicode sequence is correct.

Preeti is a separate legacy font mapping, so Unicode component sequences cannot simply be assumed to match Preeti keystrokes. Use a layout-specific chart and exam instructions for the method you need. Romanized input may create conjuncts through transliteration rules rather than direct component entry.

When you are checking a conjunct, distinguish the underlying text sequence from how a font shapes it. A Unicode string can contain multiple code points that combine into a ligature, and a legacy Preeti glyph may use a different key altogether. Copy a sample into a Unicode-aware text editor to inspect it if needed. Then practice the keystrokes expected by your selected layout, rather than assuming the visible conjunct is a single physical action.

If a conjunct looks different on two devices, first check whether the same underlying characters are present. Unicode text is shaped by the installed font and rendering engine, so ligature appearance can vary while the sequence remains valid. When diagnosing input, copy the text into a Unicode-aware editor and inspect the characters around the virama. Be careful not to delete an invisible joiner or virama while proofreading. A clear test word containing the conjunct can help you compare layouts without changing several settings at once.
