Matras are dependent vowel signs that change the sound of a Devanagari consonant. They appear before, after, above or below the base letter, even when their input key is pressed in a different order from their visible position. This can surprise new typists who expect the physical typing sequence to match the way a combined syllable is read from left to right.

Begin with a consonant and add one vowel sign at a time. Practice common pairs such as क, का, कि, की, कु, कू and के. Compare the output carefully so you can see which sign was attached and whether the base letter remained correct. Repeat the same pattern with a few other consonants before using full words.

The selected keyboard layout determines which physical keys produce a matra. Inscript, Romanized, macOS and Preeti use different mappings, so a chart from one layout may mislead you when another is selected. If a matra does not appear, check the current layout and whether Shift or another modifier is required.

Many Unicode sequences use separate code points for a base consonant and a matra. The browser shapes those code points into one visual cluster. This is why a typing exercise can count several keystrokes while showing a single syllable. A well-designed drill should judge the expected sequence for the chosen input method rather than treating every visible glyph as one physical key.

Practice matras slowly, then type short words and sentences that use them naturally. If you repeatedly confuse two signs, isolate that contrast in a short drill before taking a speed test. A teacher can make matra practice more concrete by asking learners to type a base consonant, add a sign and read the resulting syllable aloud. Students can compare how the shape changes across common examples while keeping the keyboard layout fixed. Encourage them to describe the key sequence as well as the visible result. This links script knowledge with physical movement and makes it easier to diagnose whether an error came from a missed key or a misunderstood vowel sign.

When comparing vowel signs, say the syllables aloud as you type and check that the written form represents the intended sound. This can help catch cases where the key sequence is valid but the spelling is not. Use words that learners already understand, then add unfamiliar vocabulary after the pattern is clear. Different layouts may place the signs on different keys or require Shift, so keep the same input method during each exercise. Once common matras feel comfortable, include them in sentence practice to build fluency in context.
